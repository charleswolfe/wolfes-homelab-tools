How to make a paper wallet safely
  1. Load this page, then disconnect from the network (Wi-Fi off, cable out). Everything still works offline.
  2. Use a private/incognito window without extensions, ideally on a freshly booted machine.
  3. Print to a printer you trust. Avoid network, cloud or shared office printers, which can keep copies.
  4. Close the tab (or press Clear) before reconnecting.
  5. Verify the paper: type the private key into “Check a private key” and confirm it shows the printed address.
  6. Send a small amount first and confirm it arrives before sending more.
  7. Store the paper somewhere dry and secret. Anyone who can read the private key can spend the funds, and if the paper is lost, so are the funds.

Spending from a paper wallet

Sweep, don’t reuse. When you spend, move the whole balance into a normal wallet in one go (“sweep”), then treat the paper as used.

Bitcoin Core (descriptor wallet): use the descriptor printed on the card, including its #checksum:

bitcoin-cli importdescriptors '[{"desc":"wpkh(K…)#xxxxxxxx","timestamp":"now"}]'

Use "timestamp": 0 instead of "now" if funds may already have arrived, so Core rescans the chain.

Electrum: File → New → Import Bitcoin addresses or private keys, or Wallet → Private keys → Sweep. Prefix the key with its type: p2wpkh:K…, p2wpkh-p2sh:K… or p2pkh:K…. Electrum can’t import Taproot keys; use Bitcoin Core or Sparrow with tr(K…).

Not password-protected. These keys aren’t BIP 38 encrypted. Anyone who can read the private key can spend the funds.
