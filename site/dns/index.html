DNS Lookup

Look up a domain’s records, or an IP address’s reverse name, through a public DNS-over-HTTPS resolver or your own. Compare resolvers to check whether a change has spread.

Using your own resolver

Lookups run in your browser as DNS-over-HTTPS (RFC 8484) GET requests, so a resolver works here only if it serves DoH and allows requests from web pages (it must send an Access-Control-Allow-Origin header). Cloudflare, Google and Control D do; many others, including AdGuard DNS, Mullvad, OpenDNS and NextDNS, don’t. Quad9 does only over HTTP/2, so it fails as soon as the browser switches to HTTP/3.

Same-origin route. Choose “This server, /dns-query” and have the reverse proxy in front of Homelab Tools forward that path to your resolver’s DoH endpoint. The browser then sees a same-origin request, so CORS doesn’t apply. With Caddy:

tools.home.lan {
	handle /dns-query {
		reverse_proxy https://adguard.home.lan {
			header_up Host {upstream_hostport}
		}
	}
	reverse_proxy homelab-tools:8080
}

Pi-hole has no DoH server of its own; run a DoH server in front of it and route to that. AdGuard Home and Technitium serve DoH at /dns-query once encryption is enabled.

Plain HTTP. When this site is served over HTTPS, browsers block requests to http:// resolvers.
