How to use it

  1. Plug in your keyboard. It needs firmware with VIA enabled (most QMK keyboards sold as “VIA compatible”).
  2. Open VIA and click Authorize device. Pick your keyboard in the browser’s prompt.
  3. Remap. Changes are written to the keyboard straight away and stay on it, so no software is needed afterwards.
My keyboard isn’t recognized

Check the firmware. The keyboard must run QMK with VIA enabled. Stock firmware from many brands doesn’t.

Not in the catalog? Get your keyboard’s VIA definition (a .json file) from its maker. In VIA, open Settings → turn on Show Design tab → Design → Load draft definition, then authorize the keyboard again.

Nothing happens on “Authorize device”? On Linux, give your user access to hidraw devices with a udev rule; on Windows and macOS no setup is needed.

About this copy

VIA is open-source software by the VIA team, licensed under the GNU GPL v3. This copy is built from the official source (the-via/app) with changes that make it work offline and privately and fit this site:

  • keyboard definitions, fonts and the 3D decoder are served from this server instead of the internet;
  • links to outside sites (Discord, GitHub, docs) and GitHub gist syncing are removed;
  • the commercial Gotham Rounded font is replaced with the open Fira Sans;
  • it uses this site’s header, colours and light/dark setting, and it’s a normal page rather than an app your browser offers to install.

The exact patches and build script are in scripts/via/ of this project, so the copy can be rebuilt from source.
